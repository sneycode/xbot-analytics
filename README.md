# XBot Analytics

[![Build Status](https://github.com/sneycode/xbot-analytics/actions/workflows/tests.yml/badge.svg)](https://github.com/sneycode/xbot-analytics/actions/workflows/tests.yml)
[![codecov](https://codecov.io/gh/sneycode/xbot-analytics/branch/main/graph/badge.svg)](https://codecov.io/gh/sneycode/xbot-analytics)

XBot Analytics is a Python-based tool designed to log and analyze social media post engagements. It tracks likes, comments, and timestamps, providing insights to optimize posting strategies.

## 🚀 Features

- 📊 Tracks likes and comments per post
- 🕒 Records timestamped analytics
- 📝 Logs activities using Python's logging module
- ✅ Includes unit tests with pytest
- 🔄 Continuous Integration with GitHub Actions
- 📈 Code coverage reporting via Codecov
